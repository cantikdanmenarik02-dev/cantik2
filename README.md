# Lencak Android Studio

Landing page portfolio untuk Lencak Android Studio — studio pengembang aplikasi Android.

## Menjalankan secara lokal

Buka `index.html` di browser, atau gunakan static server pilihan Anda.

## Struktur

- `index.html` — markup halaman dan logo SVG
- `styles.css` — desain responsive mobile-first
- `script.js` — menu mobile dan tahun footer dinamis
